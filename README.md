# 이미지 카드 편집기

이미지를 불러와 원하는 비율과 텍스트를 적용하고, 완성된 이미지를 PNG로 저장할 수 있는 웹 기반 이미지 카드 편집기입니다.

## 주요 기능

* PNG / JPEG 이미지 불러오기
* 카드 비율 변경

  * 1:1
  * 4:5
  * 9:16
* 텍스트 입력 및 수정
* 글자 크기 조절
* 글자 색상 조절
* 텍스트 위치 조절
* 편집 결과 실시간 미리보기
* 이미지 카드 PNG 다운로드
* 템플릿 저장 / 불러오기 / 수정 / 삭제
* 템플릿 JSON 내보내기 / 가져오기
* 잘못된 JSON 및 필수 필드가 누락된 JSON 검증
* 새로고침 후 저장된 템플릿 유지

## 사용 방법

1. 이미지를 선택합니다.
2. 카드 비율과 텍스트를 설정합니다.
3. 글자 크기, 색상, 위치 등을 조절합니다.
4. 완성된 카드를 PNG로 다운로드합니다.

### 템플릿 사용

작성한 설정은 템플릿으로 저장할 수 있습니다.

* **저장**: 현재 편집 설정을 새로운 템플릿으로 저장
* **불러오기**: 저장된 템플릿의 설정 적용
* **수정**: 템플릿 이름과 현재 편집 설정 변경
* **삭제**: 저장된 템플릿 삭제

템플릿 데이터는 JSON으로 내보내거나 가져올 수 있습니다.

## Assignment 5

### 대화가 끊겨도 이어지는 프로젝트

기존 `card-studio`에 작은 기능 개선을 적용하고, 서로 다른 AI 작업 세션이 이전 대화 내용을 전달받지 않은 상태에서도 저장소와 인수인계 문서만으로 작업을 이어갈 수 있는지 확인했습니다.

### 개선 내용

**템플릿 이름 중복 저장 방지**

템플릿 저장 및 수정 과정에 다음 정책을 적용했습니다.

* 이름 앞뒤의 공백을 제거한 뒤 비교
* 빈 문자열 또는 공백만 입력된 이름 저장 방지
* 동일한 템플릿 이름의 중복 저장 방지
* 편집 시 다른 템플릿과 동일한 이름으로 변경 방지
* 영문 대소문자는 구분

  * `Travel`과 `travel`은 서로 다른 이름

### 작업 흐름

작업 시작 전에 T01~T10의 고정 검사를 정의하고, AI A가 먼저 기능을 구현했습니다.

AI A의 작업 상태를 인수인계 문서에 기록한 뒤, AI B가 이전 대화 전문 없이 저장소와 인수인계 문서만을 참고하여 작업을 이어갔습니다.

```text
고정 검사 설정
      ↓
AI A 작업
      ↓
A 작업 상태 보존
      ↓
handoff.md 작성
      ↓
AI B 작업
      ↓
동일한 T01~T10 재검증
```

인수인계 문서는 다음 7개 항목으로 구성했습니다.

1. 목표
2. 현재 상태
3. 실행 명령
4. 통과 검사
5. 남은 문제
6. 다음 행동
7. 건드리지 말 것

### 고정 검사

작업 시작 전에 T01~T10의 ID, 입력, 기대값을 고정했습니다.

AI A 작업 중에는 자동 테스트 하네스에서 VM 재실행으로 인한 오류가 발생했습니다.

AI B는 앱의 템플릿 중복 방지 로직 자체는 유지하고, 테스트 하네스의 문제를 수정한 뒤 동일한 T01~T10을 다시 실행했습니다.

### 실제 작업 기록

공통 작업 제한은 다음과 같이 설정했습니다.

* 작업 시간: AI 세션당 30분
* 요청 / 호출: AI 세션당 10회

측정 결과:

| 항목         |        AI A |         AI B |
| ---------- | ----------: | -----------: |
| 작업 시간      |    약 9분 11초 |       6분 13초 |
| 요청 / 호출    |         26회 | 확인 가능한 기록 없음 |
| 최종 T01~T10 | 완료 전 테스트 오류 |   10/10 PASS |

AI A의 실제 요청·호출 수는 사전에 정한 10회 상한을 초과했습니다. 해당 결과는 임의로 수정하지 않고 그대로 기록했습니다.

AI B의 요청·호출 수는 현재 확보된 기록에서 정확하게 확인할 수 없어 추정하지 않았습니다.

## 테스트

다음과 같은 입력을 기준으로 기능을 확인했습니다.

* PNG / JPEG 이미지
* 긴 한글 및 영문 혼합 텍스트
* 줄바꿈
* 이모지
* 빈 텍스트
* 세로형 / 가로형 이미지
* 투명 PNG
* 매우 긴 텍스트
* 큰 글자 크기
* 텍스트 위치의 극단값

또한 템플릿 생성, 불러오기, 수정, 삭제 및 새로고침 후 저장 상태 유지 기능을 확인했습니다.

JSON 기능은 정상적인 JSON 복원뿐 아니라 문법 오류와 필수 필드 누락 상황에서도 기존 템플릿이 유지되는지 확인했습니다.

## 재현·통과 확인

**어디로 가나요:** 공개 결과물 URL

**무엇을 하나요:**

1. 이미지를 선택하고 텍스트와 비율을 변경합니다.
2. 템플릿을 저장한 뒤 불러오기 / 수정 / 삭제를 확인합니다.
3. JSON 내보내기와 가져오기 및 PNG 다운로드를 확인합니다.

**무엇이 보이면 통과:**

이미지가 정상적으로 표시되고, 텍스트와 비율 변경이 미리보기에 반영되며, 템플릿과 JSON이 정상적으로 저장·복원되고 PNG가 정상적으로 다운로드됩니다.

Assignment 5의 템플릿 이름 중복 검사에서는 `T01~T10`이 모두 `PASS`로 표시되는지 확인합니다.

**안 될 때:**

오류 메시지를 확인하고 기존 편집 내용 및 저장된 템플릿이 유지되는지 확인합니다.
